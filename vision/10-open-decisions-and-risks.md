## Risk register

Each risk: the threat, its mitigation, and the bootstrap **load test** that addresses it.

| Risk | Threat | Mitigation | Load test |
|---|---|---|---|
| **Income concentration / window closes** | Funders design around, litigate, retaliate, or the AI bubble pops → funding evaporates | Un-removable toll (SaaS); **race income → endowment** before the window closes; "never build an un-endowed obligation" | Endowment fully covers existing system at 3.5% draw |
| **Binational desal politics / ESA** | Cross-border agreement, national-monument crossing, totoaba/vaquita brine objection stall the plant (the historical failure of the real proposal) | ZLD brine processing (turns liability into selling point); treat as a patient permits megaproject, not a software-speed build | Permits secured; pilot proves ZLD |
| **Fusion non-delivery** | Helion misses 2028 / never reaches net electricity | Never on the critical path; solar baseline carries the water; PPA, not equity | Solar+desal pilot proves the baseline stands alone |
| **Aircrete QC at scale** | Inconsistent strength, shrinkage cracking, weather degradation | Batch strength testing, fiber reinforcement, render exposed faces, foam generator; keep load path in the frame | Aircrete pilot batch trials |
| **Founder handoff fails (Pullman)** | Power stays fused in founder; "sell to union" stays discretionary | **Self-binding first** — transfer triggers legally pre-committed before any build | Town can demonstrably resist the founder (Phase 3) |
| **Water-node capture** | Whoever controls the desal intake holds the system hostage | Strongest constitutional protection; widest governing coalition | Governance vehicle for the node ratified before scaling |
| **Over-securing / stall** | Bootstrapping becomes infinite caution; never launch | "Secure" = bears load, not flawless; window forces pace; explicit thresholds | Each platform's load test passed, then move |
| **Goodhart on flourishing** | Treating happiness as an output quota re-introduces fear, killing the science | Non-coercion structurally encoded; measure *inputs* not output KPIs; freedom to not produce | No output-linked happiness metrics exist |
| **Market-purism capture** | Project drifts into "just another startup," market logic strip-mines the commons | Market funds *non-market* institutions (CLT/trust/endowment); markets only for funding + competitive-business layers | Essential monopolies held in trust, not co-op-ized |
| **Clone-and-paste sterility** | Spawning identical hexes → dead, characterless towns (high-modernist failure) | Standardize shell, vary fill; let towns diverge in culture/specialization | Each new town develops distinct character |

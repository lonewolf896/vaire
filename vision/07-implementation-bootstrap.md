# 07 — Implementation: The Bootstrap

The master process. Secure footing, then ascend — one platform at a time, each with an
explicit load test, each terminal-viable.

## The fractal pattern

The same move repeats at every scale: secure a platform → use it to reach the next → never
commit weight until the current one bears load.

| Layer | Platform you secure | "Secure footing" = (load test) | Enables |
|---|---|---|---|
| **Capital** | one fully-endowed town | income-stop-proof (endowed at 3.5% draw) | the next town |
| **Material** | an aircrete batch | batch strength-tested | the structure |
| **Energy** | the solar baseline | output + membrane-durability measured | desal → Mg → fusion *option* |
| **Water/Food** | desal (piloted) | membrane + crop yield proven on real feedwater | CEA → food system |
| **Governance** | constitution + self-binding | triggers fired; town can resist the founder | businesses → union handoff → spawn |
| **Space** | one hex shell | built + governed + grown its own character | stamp the next hex |
| **Epistemics** | one variable | turned trustable by a cheap test (`08`) | the commitment it gates |
| **Cognition** | people's base | scarcity + fear removed (Maslow floor) | creativity, then science |

## The discipline (what makes bootstrapping real, not wishful)

1. **Explicit load test per platform** — "secure" is a criterion, never a feeling.
2. **Every rung terminal-viable** — if everything halts here, what you have still stands.
   No cantilevers. (Strict generalization of "never build an un-endowed obligation," `02`.)
3. **Anti-stall threshold** — "secure" = *bears load*, not *flawless*. The closing funding
   window (`02`) forces pace: don't camp on a platform.
4. **Dependency order** — start at the break-in point (prerequisite-free first move); kill
   circular dependencies (e.g., "cheap heavy water needs cheap power needs fusion" — solar
   breaks the loop).

## The build sequence (backcast from the end state)

End state: *a federation of capped, self-governing equilibrium hex-towns, running on
endowment returns, with distributed ownership, able to resist capture — including by the
founder.* Work backward:

| Phase | Build | "Hard first" logic / load test |
|---|---|---|
| **0. Lock** | Constitution, CLT, endowment vehicle, **transfer triggers** — *before any dirt moves*. Sign first licenses (price the income). | **The first thing made hard is the founder's exit.** Load test: triggers legally binding; first-license dollars observed. |
| **1. Shell** | Hard layer of *one* hex: land, water spur, power, rail, structural frames, monopoly services at cost. | De-risk the template on a single unit. Load test: one town fully built + endowed (income-stop-proof). |
| **2. Fill** | Residents/co-ops move in: aircrete infill, businesses, personalization, gardens. Seed basic businesses. | Soft layer grows. Load test: town functioning; businesses viable. |
| **3. Hand off** | Transfer triggers fire **on schedule, not on whim**; governance localizes. | The real test: **can the town resist the founder?** |
| **4. Spawn** | Stamp the next hex shell; let it diverge. | Cap-and-spawn. Endowment funds expansion after income fades. |

## Pace vs. footing (the productive tension)

- **Don't rush the step** (Durable/solvent-first; never trade endowment coverage for speed).
- **Don't camp on the platform** (the licensing window closes; rigor is the speed
  multiplier, so move once the load test passes).
- The art is the **threshold** — set it explicitly per platform (the load tests above), hit
  it, ascend.

## Reconciling bootstrapping with the grand vision

- **Ambition = the direction; bootstrapping = the method.** Climb toward the summit; refuse
  to skip rungs.
- Because every secured platform is itself a complete win, **success ≠ reaching the final
  federation** — it is every durable rung along the way. Even the pessimistic outcome (one
  rock-solid town) is a win. This dissolves the all-or-nothing fragility of grand visions.
- The method models the goal: low-fear, anti-fragile, never-bet-the-farm. And "secure
  footing, then ascend" is transmissible — it goes in the portable hard-shell culture that
  replicates with every town.

# 09 — Evidence & Sources

Grounding for the plan's load-bearing claims, with confidence notes. **Caveat:** many
figures are from web research; several primary PDFs were unfetchable, so some rest on
multiple corroborating secondary summaries. Confirm headline numbers against primary
sources before they drive an irreversible commitment. Confidence: **Strong** (peer-reviewed
/ large-N), **Moderate** (single study / corroborated secondary), **Contested** (mixed
evidence), **Promoter** (source has an interest — treat with caution).

  [Brown, Perkins & Brown 2004](https://cdn-dev.vanderbilt.edu/t2-my-dev/wp-content/uploads/sites/249/2011/09/BrownPerkinsBrown.2004.Incivilities-place-attachment-and-crime.JEP_.pdf)
